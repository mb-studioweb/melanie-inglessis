# Untitled Film — template cloné

Miroir statique de [untitledfilm.framer.website](https://untitledfilm.framer.website), sans le bouton **Buy Template** ni le badge **Made in Framer**.

## GitHub Pages

Site prévu sur : **https://mb-studioweb.github.io/melanie-inglessis/**

Activation (une fois) dans le repo GitHub :

1. **Settings** → **Pages**
2. **Source** : *GitHub Actions*
3. Le workflow `Deploy to GitHub Pages` publie le dossier `template/` à chaque push sur `main`

## Aperçu local

```bash
cd template && python3 -m http.server 8080
```

Ouvrir http://localhost:8080
