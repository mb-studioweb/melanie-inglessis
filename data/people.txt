 Artists / People directory • 10 profiles
 Companion brief to the first MB Studio portfolio document • 22 September 2026



 Goal: build a dedicated PEOPLE / ARTISTS section in the concept portfolio. Each person gets a profile page that can
 aggregate every verified Mélanie Inglessis project associated with that person.
 Important: “current” means the person is named in Mélanie’s current Forward Artists bio as of this research.
 “archive” means documented past work but this brief does not claim an ongoing client relationship. Do not turn
 archive names into “current clients.”


 RECOMMENDED DIRECTORY ORDER

 Portman • Lea Michele • Britney Spears

 The first eight are especially defensible because Forward Artists currently names them in Mélanie’s client roster. Lea
 Michele and Britney Spears are included as strong archive relationships to reach the requested ten while broadening
 the site into television/music history.

 DATA MODEL FOR CURSOR
 Suggested structure for each person record:
 slug
 name
 profession
 relationshipStatus: current | archive
 heroImage
 heroImageSource
 summary
 projectSlugs[]
 sourceUrls[]

 Create the People directory from data rather than ten hard-coded pages. Each person page should query the
 same central project dataset used by WORK. That way, a project such as “Jenna Ortega / Vogue Mexico / 2025”
 appears both under WORK and automatically under Jenna’s PEOPLE page without duplicated content.


 NAVIGATION RECOMMENDATION
 HOME / WORK / PEOPLE / ABOUT / CONTACT

 On mobile, PEOPLE should open a clean portrait grid. The card only needs the person’s name and profession. Avoid
 celebrity biographies: this is Mélanie’s portfolio, so every page should remain focused on her makeup work with that
 person, not become a fan/biography site.
